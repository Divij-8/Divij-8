### Double-Entry Distributed Ledger System

A transaction-focused backend built to explore **financial consistency, concurrency and reliable state transitions**.

**Java 21 · Spring Boot · PostgreSQL · Redis · JWT · Testcontainers**

- Double-entry ledger architecture
- Idempotent transfers
- Pessimistic locking with ordered lock acquisition
- Transactional consistency
- JWT authentication
- Integration testing with Testcontainers
- GitHub Actions CI

**Focus:** concurrency, consistency, transactions and backend architecture.

## 🛡️ AegisMCP

### Security & Control Plane for MCP Systems

Exploring the infrastructure required to let AI agents interact with external tools **without turning tool access into an uncontrolled execution boundary**.

**MCP · AI Agents · API Security · Policy · Execution Control**

The project focuses on questions such as:

- Who can access a tool?
- What operations are permitted?
- Where should execution boundaries exist?
- How can tool activity be observed and audited?

**Currently building.**

## 🎮 Kaiser Quest

### Educational RPG with an Adaptive Knowledge Engine

A collaborative **2.5D pixel-art educational RPG** where learning is part of the game mechanics rather than a quiz layered onto a game.

**Unity 6 · C# · Python · FastAPI · Adaptive Learning**

- Mastery-based progression instead of traditional level gates
- Bayesian Knowledge Tracing
- Adaptive question difficulty
- Named misconception detection
- Concept dependencies and forgetting
- AI-generated content → validation → difficulty estimation → human verification
- Offline-first knowledge engine running inside the game
- Python backend for content generation, validation and analytics
- Automated Unity and Python testing

The system currently models **88 concepts**, with a verified question pipeline and separate Unity/Python implementations of the knowledge engine.

**Role:** Collaborating with the Kaiser Quest team.

[View Repository →](https://github.com/arnav-mishra28/KaiserQuest)
